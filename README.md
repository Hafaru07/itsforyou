# Its For You: prototipe landing page

Landing page satu layar untuk memperkenalkan konsep halaman ucapan personal pada subdomain `nama.itsforyou.web.id`.

- Konten contoh di kartu pratinjau bersifat ilustratif; subdomain contoh belum aktif.
- Kolom nama hanya mengubah contoh alamat dan sapaan di browser. Tidak menyimpan atau mengirimkan data.
- Tombol utama membuka `https://tataweb.id/` untuk pemesanan.
- Dibuat sebagai HTML/CSS/JavaScript statis tanpa dependensi.

Desain memakai kartu ucapan sebagai bentuk halaman, dengan biru dari logo sebagai warna utama. Dials: ENERGY 2 / RHYTHM 2 / MOTION 1. Satu tautan pemesanan menjadi aksi utama; kolom nama menunjukkan konsep alamat personal tanpa menyiratkan bahwa subdomainnya sudah aktif.

Untuk melihat versi lokal, jalankan `py -3 -m http.server 4173 --directory dist` dari folder ini, lalu buka `http://127.0.0.1:4173/`.
