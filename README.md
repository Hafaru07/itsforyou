# Its For You — prototipe landing page

Landing page satu layar untuk memperkenalkan konsep halaman ucapan personal pada subdomain `nama.itsforyou.web.id`.

- Konten contoh di kartu pratinjau bersifat ilustratif; subdomain contoh belum aktif.
- Tombol utama membuka `https://tataweb.id/` untuk pemesanan.
- Dibuat sebagai HTML/CSS statis tanpa dependensi atau JavaScript.

Untuk melihat versi lokal, jalankan `py -3 -m http.server 4173 --directory dist` dari folder ini, lalu buka `http://127.0.0.1:4173/`.
